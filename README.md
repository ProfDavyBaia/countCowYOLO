# Animal Detection in Aerial Images

Projeto para detecção automática de animais em imagens aéreas utilizando modelos de visão computacional baseados em YOLO.

Este projeto utiliza Python e bibliotecas de deep learning para identificar animais (ex.: bovinos) em imagens capturadas por drones ou satélites.

---

## Objetivo

Desenvolver um pipeline de detecção de objetos capaz de identificar animais em imagens aéreas para aplicações em:

- Zootecnia de precisão
- Monitoramento de rebanhos
- Agricultura digital
- Análise ambiental
